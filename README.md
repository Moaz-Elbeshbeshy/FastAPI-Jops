Jobs API (FastAPI)
A simple API for user authentication and managing job listings, built with FastAPI, MongoDB, and secured with JWT.
Setup

Clone the repository:
git clone <repository-url>
cd Jobs-API-FastAPI


Create a virtual environment:
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate


Install dependencies:
pip install -r requirements.txt


Set up environment variables:Create a .env file in the project root and add your MongoDB connection string:
MONGO_URI=mongodb://localhost:27017/jobs_api
JWT_SECRET=your-secret-key


Run the server:
uvicorn app:app --reload


Populate the database with sample data (optional):
python populate_db.py



The API will be available at http://localhost:8000. Access the Swagger UI at http://localhost:8000/docs.
Database Connection

Uses Motor (async MongoDB driver) to connect to MongoDB.
Configure the MongoDB URI in the .env file.
The database connection is initialized on startup in app.py.

Routes Overview

/api/v1/auth: Handles user registration (/register) and login (/login).
/api/jobs: Handles CRUD operations for jobs (create, read, update, delete).

User Model Details

The user model validates the email field using a regex pattern.
Passwords are hashed using bcrypt before storage.
JWT tokens are generated for authentication.

User Registration Flow

Validates required fields (name, email, password).
Checks for duplicate emails.
Hashes the password using bcrypt.
Saves the user to the database.
Returns a JWT token and user details.

User Login Flow

Validates email and password.
Checks if the user exists and the password is correct.
Returns a JWT token if credentials are valid.

Error Handling

Validation Errors: Handles missing or invalid fields.
Duplicate Email Errors: Prevents registering the same email twice.
Invalid IDs: Handles malformed MongoDB ObjectIds.
Authentication Errors: Returns appropriate 401 errors for invalid tokens or credentials.

Security Setup

CORS: Configured to allow cross-origin requests (see core/config.py).
JWT Authentication: Secures endpoints with OAuth2 bearer tokens.
Password Hashing: Uses bcrypt for secure password storage.
Rate Limiting: Not implemented in this version but can be added using FastAPI middleware.

API Documentation
The API is documented using Swagger UI, accessible at http://localhost:8000/docs. The OpenAPI schema is automatically generated by FastAPI.
Testing with Swagger UI

Open http://localhost:8000/docs in your browser.
Click the Authorize button and enter a JWT token obtained from /api/v1/auth/register or /api/v1/auth/login.
Test endpoints like creating or retrieving jobs directly from the UI.

Testing with Postman

Register a user via POST /api/v1/auth/register to obtain a JWT token.
Log in via POST /api/v1/auth/login to obtain a token.
Set the token as a Bearer Token in the Authorization header.
Test endpoints like POST /api/jobs or GET /api/jobs.

Notes

Ensure MongoDB is running locally or provide a valid MongoDB URI.
The API uses async/await with Motor for non-blocking database operations.
For production, secure the JWT_SECRET and consider adding rate limiting and input sanitization.
